# PDF Blender Website Design

Retain the selected simpler SaaS template's centered hero, neutral surfaces, compact navigation and responsive cards. Product accents are coral: light #C9021E and dark #E74856. A subdued halo supports the main screenshot; avoid heavy animation and large empty gaps.

The homepage contains a concise hero and real application screenshot, six feature cards, three usage steps, a manual selector for the remaining three configuration screenshots, eight short FAQ entries and a compact GitHub CTA. Pricing, testimonials, fabricated statistics and partner logos are removed.

The supplied screenshots show the actual English light-mode app. Keep their full aspect ratio and all controls intact in both website themes. Do not simulate localization or dark screenshots. The transparent product logo is used in the header/footer; the Bitcookies wordmark appears at the footer with a light backing in dark mode for readability.

The privacy article is a separate page with a contents list, comfortable line spacing and a 780px maximum width. Both page types share language switching and system/light/dark controls. On mobile, feature cards and steps become one column and navigation collapses to an inline menu with Escape support.

Use server-rendered copy and local assets. Only the mobile menu, theme selector, screenshot tabs and Radix FAQ accordion need client state. Respect reduced motion, use visible keyboard focus, preserve heading order and provide descriptive image alternatives. Images support rather than replace readable text.
